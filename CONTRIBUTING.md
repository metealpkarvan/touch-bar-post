# Contributing

Open an issue with your macOS version, CPU family, presence of a physical Touch Bar, reproduction steps and expected behavior. Use fictional data; remove private titles and backup content before sharing.

Build and verification commands are in README.md. Keep core mutations deterministic and add checks when changing persistence, deadlines, queue selection or imports. Run AppKit smoke checks after UI/Touch Bar changes. Update Turkish and English controls/guides together. Preserve both Universal slices and native Mac CI. Physical hardware and notification delivery must be reported separately from item/action tests.
